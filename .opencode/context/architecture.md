# Architecture — Urutaú Limited

## Build pipeline

`_config.ts` wires Lume v3.3.3 plugins in this order:

| Plugin          | Purpose                                                     |
| --------------- | ----------------------------------------------------------- |
| `jsx`           | TSX component support                                       |
| `favicon`       | Generates favicon from SVG                                  |
| `pagefind`      | Client-side search index                                    |
| `redirects`     | URL redirects                                               |
| `googleFonts`   | Downloads Lora, writes `@font-face` to `output/urutau.css`  |
| `postcss`       | CSS processing                                              |
| `base_path`     | Normalize resource paths                                    |
| `slugifyUrls`   | Accent folding (Á to A, etc.)                               |
| `ogImages`      | OpenGraph image generation                                  |
| `metas`         | Meta tag generation                                         |
| `jsonLd`        | Structured data                                             |
| `codeHighlight` | highlight.js with atom-one-dark/light themes → `urutau.css` |
| `sitemap`       | XML sitemap                                                 |
| `feed`          | RSS + JSON feeds at `/posts.rss`, `/posts.json`             |
| `robots`        | robots.txt with AI bot blocks                               |
| `seo`           | SEO error reporting                                         |
| `wellKnown`     | `/.well-known/security.txt`, trust.txt, GPC                 |
| `readingInfo`   | Adds reading time and word count to posts                   |

CSS pipeline: `googleFonts` -> `output/urutau.css` <- `codeHighlight` <-
`src/styles.css` (appended via `site.add("styles.css", "urutau.css")`)

│   ├── HtmlDocument.tsx    <html> shell (doctype, head, body)

│   ├── siteFooter.tsx      Site footer
│   ├── html_includes.tsx   Shared head elements

│       └── WikiProjectCard.tsx
├── posts/                  Blog entries (markdown + _data.ts)

├── types/mod.ts            PostMeta + DebtEntry interfaces

## Key files

| File               | Role                                                             |
| ------------------ | ---------------------------------------------------------------- |
| `_config.ts`       | Site config, plugin registration, static file routing            |
| `deno.json`        | Import map (`$urutau/*`, `@std/*`, `lume/*`), permissions, tasks |
| `src/styles.css`   | Custom CSS appended to autogenerated `output/urutau.css`         |
| `src/_data.yml`    | Site-level metadata                                              |
| `src/types/mod.ts` | Shared TypeScript interfaces                                     |

## Front matter conventions

All markdown pages (`src/posts/`, `src/*.md`) use YAML front matter:

```yaml
---
title: "Page title"
description: "SEO description"
layout: layout.tsx          # Points to src/_includes/layouts/
type: post | page
image: /img/og-image.png    # OpenGraph
lang: es                    # "es" default
tags: [tag1, tag2]          # Posts only
author: Author Name         # Posts only
date: 2025-01-15            # Posts only
---
```

`type: post` -> these are listed in RSS feed, tagged, dated. `type: page` are
standalone website pages.

## URL rules

- `slugifyUrls` replaces accented chars: `Á to A`, `é to e`, `í to i`, `ó to o`,
  `ú to u`
- Slugs derived from filenames/titles via Lume's default slugification

## Component import convention

```tsx
import SiteNavbar from "$urutau/components/siteNavbar.tsx";
import { PostMeta } from "$urutau/types";
```

`$urutau/` resolves via `deno.json` import map to `./src/`.
